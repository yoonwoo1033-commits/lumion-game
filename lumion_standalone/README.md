# LUMION 독립 데모

기존 포켓몬 프로젝트와 무관한 Streamlit + SQLite 게임입니다.

## 실행
1. Python 3.10 이상 설치
2. 터미널에서 프로젝트 폴더로 이동
3. `python3 -m pip install -r requirements.txt`
4. `python3 -m streamlit run app.py`

## 구현 범위
- 달빛 숲 20종, 희귀도, 레벨, 오로라 1/500
- 탐험 10코인, 캡슐 상점, 포획, 도감, 보관함
- SQLite 영구 저장, 트랜잭션으로 중복 차감 방지
- 일부 진화 예시 (레벨 성장 기능은 아직 없음)
- CSS 부유/광채 애니메이션 (캐릭터 고유 GIF 미포함)
- 하루 한 번 수면 기록 참여 보상 (수면 입력값 저장 미구현)

## 주의
- 로컬 개인 테스트용입니다. 인증 없는 URL 식별 방식이므로 공개 배포 금지.
- `lumion.db`가 자동 생성되며 게임 기록이 저장됩니다. 이 파일을 백업하세요.
- 여러 명이 사용하려면 Supabase Auth와 서버측 RPC/RLS로 교체해야 합니다.
- 진짜 24프레임 이상 캐릭터 애니메이션은 프레임 이미지 제작 후 연결해야 합니다.
